# Upgrade to TenonAdmin 0.5.0

## What changed

| Area | Change |
|---|---|
| Packages | `TenonAdmin` **0.3.3 → 0.5.0**; added `TenonAdmin.Excel` **0.5.0** |
| Frontend | Re-extracted `web/` from `Tenon-Net/TenonAdmin/web#v0.5.0`; restored CRM + trial-login customizations |
| CRM | Customer **import / export** wired (profiles, 6 import endpoints + export, menu buttons, trial role grants) |
| Demo policy | `CrmDemo:ImportDryRun` defaults **true** — wizard fully usable, commit does not write |
| Seeds | Import/export button menus `1004–1008`; role-menu grant Ids use formula `2000 + ri*20 + mi` (safe on upgrade) |

## Why not DemoMode for import

`TenonAdmin:DemoMode` rejects every non-GET with `41002`, so preview/validate/commit never run. Public demo should leave DemoMode off and use dry-run + missing write grants instead.
