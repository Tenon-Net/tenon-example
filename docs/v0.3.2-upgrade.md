# v0.3.2 Upgrade And Launch-Profile Fix Adoption

Date: 2026-07-24

`0.3.2` shipped the fix for finding 1 in [the v0.3.1 revalidation record](v0.3.1-revalidation.md): the `tenon-app` template now ships `Properties/launchSettings.json`. This record covers upgrading this repository and replacing the interim `$env:ASPNETCORE_ENVIRONMENT` workaround with the same file a fresh `dotnet new tenon-app` now generates.

## Changes

- `tenon-example.csproj` now references `TenonAdmin` `0.3.2`.
- `web/` re-extracted with `npx degit Tenon-Net/TenonAdmin/web#v0.3.2 web --force`.
- TenonAdmin tag `v0.3.2` dereferences to commit `14a5b352a78c512f2b9ba3b4de6361c93103b4cd`.
- Added `Properties/launchSettings.json`, matching the file now shipped by `TenonAdmin.Templates@0.3.2`, pinning `ASPNETCORE_ENVIRONMENT=Development` and `applicationUrl=http://localhost:5100`. The README no longer instructs setting the environment variable by hand.
